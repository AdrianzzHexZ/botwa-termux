# HEXZ-BOT-WA

## Install Termux
```bash
pkg update -y && pkg upgrade -y
pkg install nodejs git ffmpeg -y
```

## Masuk folder
```bash
cd HexZ-BOT-WA
```

## Install dependency
```bash
npm install
```

## Jalankan bot
```bash
node index.js
```

## Pairing
Masukkan nomor WA format:
```bash
628xxxxxxxxxx
```

> Pairing code asli akan keluar dari WhatsApp. Label bot di project ini: `HEXZ-BOTZ`

## Catatan
- File `session/` akan otomatis dibuat.
- Kalau bot logout, hapus folder `session/` lalu login ulang.
